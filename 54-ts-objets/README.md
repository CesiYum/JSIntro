# 54 — Décrire une fiche produit

**Notion :** type, propriété optionnelle  
**Durée indicative :** 10 à 20 minutes  
**Dépendance aux autres exercices :** aucune

## Situation

Vous travaillez sur une petite fonctionnalité isolée. Tout ce qui est nécessaire se trouve dans ce dossier.

## Consignes

Définissez Produit avec id, nom et description optionnelle. Créez une fonction afficherProduit qui accepte Produit et utilise ?? pour la description manquante.

## Lancer

Lancez `npm install`, `npm run build`, puis `npm start`.

Casque : Sans description
